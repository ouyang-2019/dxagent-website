JSON 格式化工具

粘贴一段 JSON,一键格式化或压缩。解析失败时会提示原因；可定位时显示行列信息。所有处理都在浏览器本地完成,输入内容不会被上传。

就绪。输入 JSON 后点击「格式化」或「压缩」;所有处理均在本地完成。

          
提示:在输入框中按 Ctrl + Enter(macOS 为 ⌘ + Enter)可以快速格式化。本工具不发起任何携带输入内容的网络请求。

        

        
      

    


    

      

        

          
使用说明

          
这个工具能做什么

        

        

          
    
            
  • 格式化:校验并以 2 个空格缩进重新排版 JSON;结构非法时提示原因；可定位时显示行列信息。
    • 
            
  • 压缩:移除多余空白,输出单行紧凑 JSON。
    • 
            
  • 清空:同时清空输入与结果,并将焦点移回输入框。
    • 
            
  • 复制结果:把结果写入剪贴板;若浏览器拒绝授权,会提示你手动复制。
    • 
            
  • 隐私:解析与输出全部由浏览器本地完成,输入内容不会被上传或记录。
    •
