项目简介

niu-lai-video-translator 是 DX Agent 的原创项目,一个面向 Codex 的视频风格转换 Skill。它服务于「视频到视频」(V2V)的风格转换场景:先把原视频拆解为镜头级别的制作规划,再在风格转换的全过程中施加时序一致性约束。

在进入正式的风格转换之前,项目还提供本地程序化预览,用来提前验证剪辑节奏、音频与整体美术方向,把方向性的误判挡在高成本的生成环节之前。

核心能力

  • 按镜头分段的制作规划:把 V2V 转换拆解到镜头级别,逐段规划,而不是笼统处理整条视频;
  • 时序一致性约束:在镜头之间维持风格与内容的连续,降低闪烁与跳变;
  • 本地程序化预览:在本地快速生成预览,用于验证剪辑、音频与整体美术方向;
  • Codex Skill 形态:以 Skill 的形式提供给 Codex 使用,融入既有的 Agent 工作流。
