项目简介

SkillGene 是 DX Agent 的原创项目,一个 AI 能力胶囊平台。它把 Agent 可调用的能力封装为「技能胶囊」,通过 MCP(Model Context Protocol)对外提供搜索与调用入口,并内置 910+ 个预置胶囊,覆盖多类常见任务场景。

平台的定位不止是一个静态的技能仓库:胶囊可以被检索、组合,并在使用中持续演进,让 Agent 的能力库随需求生长,而不是一次性固定下来。

核心能力

  • 胶囊搜索与发现:由 MCP 驱动的技能胶囊检索,内置 910+ 个预置胶囊,Agent 可以按需找到合适的能力;
  • 按需组合:多个胶囊可以组合使用,拼装出面向具体任务的能力集合;
  • 能力演进:作为「进化系统」,胶囊在使用中不断演化,而不是一成不变;
  • MCP 集成:以 MCP 作为对接协议,便于接入支持该协议的 Agent 环境。
